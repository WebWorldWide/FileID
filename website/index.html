Make sense of tens of thousands of files — tagged, deduped, and renamed, all on your machine.

FileID tags, dedupes, restructures, and renames your local libraries with on-device AI. No cloud. No telemetry, ever. The only thing that ever leaves your machine is a model download you start yourself.

Native everywhere you work

Four real front-ends — built with each platform's own toolkit, never web tech — plus a scriptable CLI and a terminal UI for servers and NAS boxes.

macOS

SwiftUI app on the Apple Neural Engine. Ships as a native .app.

Windows

WinUI 3 / .NET, accelerated by ONNX Runtime. Ships as an .msi (x64 + ARM64).

Linux

GTK4 + libadwaita, native dark mode. Flatpak (primary), AppImage, Nix flake, AUR.

CLI

A scriptable fileid binary for headless servers, automation, and NAS pipelines.

TUI

A full ratatui terminal UI — drive the same engine over SSH.

Install on Linux

Every distro is covered. Build straight from the repo — see the packaging guide.

Six tools, one local library

Each tab is a focused job. They share one fast on-device engine — and one database that round-trips byte-for-byte across every platform.

Library

Full-text search and semantic CLIP search across your whole collection, with a fast thumbnail grid and instant preview.

People

On-device face clustering groups every photo by who's in it. You just put a name to each face — no faces ever leave the device.

Cleanup

Finds exact duplicates and perceptual near-duplicates — resizes, re-encodes, light edits — so you can reclaim space without guesswork.

Deep Analyze

On-device vision-language models write captions and propose smart renames. The picture is described locally — it never touches a server.

Restructure

Butler-grade folder reorganization with a Sankey preview of every move — review the whole plan before a single file is touched.

Settings

Manage AI models, pick your compute backend, inspect the engine and logs, and read exactly what the app does — and doesn't — do.

Privacy is the architecture

Your files never leave your machine.

FileID has no servers, no accounts, and no analytics. Everything — search, faces, captions, renames — is computed on your own CPU, GPU, or NPU. The single network request the app can make is a model download you initiate, straight from huggingface.co. CI scans every shipped binary for telemetry strings as a release blocker.

  • No cloud. Every model runs locally, with no round trip.
  • No telemetry, ever. No analytics, crash reporting, or update pings.
  • One egress, on your terms. Only a model pull you start, from Hugging Face.
  • Apache-2.0 & commercial-clean. Every default weight is Apache- or MIT-licensed.
≥140files/s target throughput on mid-tier hardware

A fast on-device pipeline that uses the GPU or NPU when present — Apple Neural Engine, ONNX Runtime (DirectML / CUDA / CoreML), MLX and llama.cpp — and degrades gracefully to CPU.
