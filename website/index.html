Privacy posture

100% on-device.
Zero telemetry.

No analytics SDKs, no crash reporters, no usage pings. The only network use is a model download you start yourself, from Hugging Face, verified against pinned hashes. CI rejects anything else.

  • Local SQLite library in your application-support folder. Delete it any time; your files are untouched.
  • Models download directly from their upstream repositories. FileID never redistributes weights, and every default weight is Apache-2.0 or MIT.
  • Reviewed egress baseline. A release gate diffs every network-capable source file against reviewed digests.
  • Binary privacy scan. Every shipped binary is checked against a deny-list of telemetry SDK strings before release.

How it's built

Two binaries. One IPC contract.

The app and the engine are separate processes talking newline-delimited JSON over stdio. A model crash never takes the window down; the engine respawns with bounded backoff.

AppFileID.app · FileID.exe · fileid-linux
  • SwiftUI · WinUI 3 · GTK4
  • Verifies the engine before spawning it
  • Auto-respawns on crash (1 s · 4 s · 16 s)
stdin / stdout · newline-delimited JSON IPC schema 1.16.0 · Swift, Rust and C# mirrors
