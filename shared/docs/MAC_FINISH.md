# Mac completion and native port handoff

Scope updated October 10, 2026: complete the Mac app first, then stop and record the remaining Linux and Windows work. Preserve the existing unlanded port changes; do not continue port feature work during this Mac pass.

## Required Mac outcomes

- Best takes: discover related attempts, accept arbitrary desired outcomes, analyze timestamped visual evidence, explain recommendations/ties/uncertainty, support correction and retained originals.
- File tools: preview batch conversion/resize, native video stabilization, social aspect variants and people tracking; validate outputs and support cancellation and Undo.
- Moments: significant timestamps, playable chapter markers, searchable evidence and a personal cast/catalog; protect reviewed moments from reanalysis.
- Names: short specific proposals based on current reviewed event/action/person evidence, conservative fallback, collision handling, preview and Undo.
- People: current compatible embeddings, bounded refresh, preserved confirmed identities/corrections, accurate display and deferred coverage; test live-source and commit races.
- Models: hundreds of curated, license-compatible models with pinned source metadata, architecture/role filtering, visible hardware/installation status, offline inference and user-initiated verified downloads. Runtime compatibility and measured quality are separate claims.
- Chat/UI: a right-side chat inspector beside the current task; consistent hierarchy, palette, springs, keyboard focus, narrow-window layout, progress/error/empty states and recovery actions.

## Design contract

Use the existing FileID visual system as the reference: LavaLamp remains the canvas, gold is the primary action/selection accent, lavender/cyan/pink distinguish supporting information, native SF typography and symbols provide utility controls. Adopt the design-ui skill's precision-software direction for dense tasks and photographic-instrument hierarchy for moment/take evidence. Keep one selected media item or task as the anchor; put secondary controls and detail in quiet rows instead of adding nested cards.

Chat opens as a persistent right-side inspector, keeps the library/task accessible, restores the current conversation, and closes with its header control or Escape. Command-K toggles it. Model browsing separates vision and text roles, searchable catalog entries, installed/compatible status and explicit download actions. Existing favorites remain stable choices; additions must not silently change the default.

## Current verification

The native products build with Swift 6. The full native suite and focused resource/attestation tests pass; the exact final count is recorded in STATE.md. Native AppKit-owned screenshots cover the chat inspector, searchable model browser and video tools. The isolated app at `/tmp/FileID-Mac-20261010.app` passes local ad-hoc signature verification and reports 265 catalog entries (72 vision/193 text) with the build resource fallback temporarily hidden. Its catalog is in packaged Resources and the Swift SDK compatibility dylib is embedded. This is a local debug artifact, not a notarized release.

Generated video workers preserve source bytes, timing, audio and Undo; opt-in enlargement renders smaller video at the requested target. Stabilization reduces normalized translation/rotation jitter by more than the required 35%/25% thresholds. It uses a translation seed before homography refinement, coordinate conversion, bounded smoothing and up to 12% covering zoom, composed with people/social framing. Temporary processing uses at most three small registration images. Real-world quality/coverage remains model- and footage-dependent.

Reviewed naming contexts and personal cast reject stale, ignored, unknown, malformed and incompatible evidence. Tests cover actual source-file changes and late title/person changes before persistence. Restructure can use reviewed titles without loading a visual model. Existing filename collision/preview/Undo behavior remains the apply path.

The approved Qwen3.5 2B download passed. A CPU-only test of its local tokenizer confirmed the concise template context used for bounded output; it is not an inference-quality result. Its actual sequence inference was refused by the unchanged available-memory guard; this is not a successful quality evaluation. Do not promote a default or claim universal event/identity accuracy from generated fixtures. Photo/video enlargement is conventional interpolation, not neural detail recovery. Current video exports are single-video/at-most-one-audio-track SDR H.264/AAC MP4; HDR, auxiliary streams and unsupported formats are explicitly rejected. Stabilization/people tracking supports up to ten minutes; stabilization supports at most 60 fps and tracking samples twice per second. Additional neural packs, arbitrary format adapters, general-object crop tracking and dense automatic cast timing are future extensions rather than enabled capabilities.
